# Floating table calibration document

`calib-floating.docx` is generated by the Layout chat's calibration script (no third-party content). Word 2021 saved it
as PDF on 3 Nov 2026; FloatingTableLayoutTests.cs checks Layout against the positions read from that PDF where ECMA-376
is silent, and against the standard where it is clear:

- T1: vertAnchor text, horzAnchor margin, tblpX 4000, 180 twips from text left and right (as d46).
- T2: page-anchored, right and bottom aligned (Layout places it exactly there, whole: decision A).
- T3: margin-anchored 1440 twips down, reaching above its paragraph (the text above flows around it).
- T4: two tables at the same position; the second has tblOverlap never (decision B).
- T5: a 60-row table anchored to its paragraph, taller than the space left (continues at the top of the next page).
- T6: anchors not stated (the standard's page and page, not Word's defaults: Q1).
- T7: a floating table in column 2, horzAnchor text (the column).
