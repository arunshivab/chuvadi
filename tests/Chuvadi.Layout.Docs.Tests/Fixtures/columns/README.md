# Column calibration document

`calib-columns.docx` is generated by the Layout chat's calibration script (no third-party content). It holds the
column cases where ECMA-376 is silent and Layout follows Word as measured from Word 2021's own PDF of this file
(3 Nov 2026):

- K1: two equal columns, separator, `w:space` not stated, text running onto page 2 (not balanced at a next-page break).
- K2: three unequal columns (2000, 2500, 3526 twips; spaces 400, 600), separator, a column break.
- K3 to K5: one column, a short two-column section between continuous breaks (balanced), one column again.
- K6: a footnote in column 1, a column break, 24 pt space before at the top of column 2, a picture positioned
  relative to the column.
- K7: the last section, starting in the next column.

`calib-lastsection-nextpage.docx` and `calib-lastsection-continuous.docx` end with a short two-column section after a
next-page and a continuous break: Word does not balance a document's last section (measured 4 Nov 2026).

The tests in ColumnLayoutTests.cs check Layout against the positions read from Word's PDF.
