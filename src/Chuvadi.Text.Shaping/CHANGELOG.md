# Changelog — Chuvadi.Text.Shaping

## Unreleased (0.1.0)

Phase 1 (D-205, D-246, D-295):

- Typed diagnostics on the result (D-246): `GlyphBuffer.Diagnostics`, `ShapedRun.Diagnostics`, `ShapingDiagnostic`,
  `ShapingDiagnosticKind` (`MissingGlyph`, `ScriptNotInFont`), each kind once per call, nothing allocated when none.
- Script lookup by OpenType tag: the Indic v.2 tag first, then the original one (R-TS-0013).
- Unicode 18.0.0 tables (D-190).
- `IsTrimmable` and `IsAotCompatible` set (D-217).

Phase 0:


- New library: `ShapingFont`, `ShapeOptions`, `Script`, `Language`, `Feature`, `TextDirection`,
  `GlyphBuffer`, `PositionedGlyph`, `ShapedRun`, `TextShaper`.
- Phase 0 shaping: character map and default advances only (no layout features yet).
- Own Unicode tables (17.0.0 in phase 0) and NFC/NFD normalisation, generated by tools/Chuvadi.Text.Shaping.UcdGen;
  the Unicode License v3 notice ships in the package.
