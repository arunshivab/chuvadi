Chuvadi.Markup — third-party notices
====================================

Chuvadi.Markup is MIT licensed. Part of its Markdown implementation closely follows the C source of
two third-party projects, and is distributed under their licence terms reproduced below:

  - cmark (https://github.com/commonmark/cmark), the CommonMark reference implementation
  - cmark-gfm (https://github.com/github/cmark-gfm), GitHub's fork with the GFM extensions

Files concerned (in the Chuvadi.Markup source):

  Markdown/Parsing/BlockParser.cs, BlockNode.cs       follow cmark src/blocks.c, node.h
  Markdown/Parsing/InlineParser.cs, InlineNode.cs     follow cmark src/inlines.c
  Markdown/Parsing/Scanners.cs                        follow cmark src/scanners.re
  Markdown/Parsing/ExtendedAutolinks.cs               follows cmark-gfm extensions/autolink.c
  GFM tables, task lists, strikethrough (in the parsers above)
                                                      follow cmark-gfm extensions/table.c,
                                                      tasklist.c, strikethrough.c
  Markdown/MarkdownHtmlRenderer.cs (output format, unsafe-URL rule and href escaping)
                                                      follows cmark src/html.c and the houdini
                                                      href escaper (houdini_href_e.c)

cmark and cmark-gfm ship the same COPYING file. It is reproduced below exactly as published
(cmark and cmark-gfm, branch master, file COPYING). Of the components it lists, Chuvadi.Markup
follows the cmark / cmark-gfm code (BSD 2-Clause, first section) and the houdini href escaper
(MIT, second section); it does not use buffer.c/chunk.h, utf8.c, normalize.py, the CommonMark
spec or the test software, whose notices are reproduced only because the file is reproduced in full.
