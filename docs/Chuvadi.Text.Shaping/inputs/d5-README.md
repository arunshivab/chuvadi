# Behaviour corpus for rule 5 (d.5)

`behaviour-3.31.0.tsv` records what Chuvadi.Pdf.Text.Shaping **3.31.0** does
on the inputs the gate does not cover. It was generated by running 3.31.0 as
a program (D-182 baseline: what users have now) and contains data only.
- **Format.** The header lines explain the format. It is the corpus format
  with three added columns: category, features on, and note. A result is
  either glyphs, or `EXCEPTION <type>: <message>`.
- **Features.** Each line lists the complete set of features that are on,
  so the line does not depend on what `ShapingFeatures.Default` means.
  3.31.0's `Default` has `cpsp` on.
- **Language.** The fonts' default language system. The engine API has no
  language argument.
- **Both call forms.** Every line was shaped with `Shape(FontFace)` and with
  `Shape(byte[])`, and the two are identical on all 732 lines.

| Category | Lines | What it covers |
|---|---|---|
| `mismatched-script` | 8 | The script argument does not match the text (for example Tamil text passed as Devanagari or Latin, Latin passed as Tamil). |
| `font-lacks-script` | 44 | Each Indic script in each of the four Latin-only fonts, and eight Indic scripts in the Devanagari font. |
| `feature` | 611 | For each of the 13 fonts: every one of the 44 switchable features flipped from 3.31.0's default, one line each. `cpsp` is included, both ways. Each font also gets the D-68 gate setting (`cpsp` off), all features off, and all features on. The text is the font's script plus a Latin line with fractions, ordinals, figures, capitals and ligatures. |
| `unpaired-surrogate` | 27 | A lone high or low surrogate, alone, inside, at the start or end, and inside an Indic cluster, in three fonts. |
| `mixed-scripts` | 28 | Other scripts inside a run: Latin, Cyrillic, Greek, CJK, emoji and Arabic in Indic runs and the reverse, plus ZWJ, ZWNJ, U+25CC, a leading virama and repeated vowel signs. |
| `long-run` | 12 | 1,000, 5,000 and 10,000 UTF-16 units, in Latin, Tamil, Devanagari and Malayalam. |
| `exception` | 2 | Empty text (`System.ArgumentException: Text must not be empty. (Parameter 'text')`) and null text (`System.ArgumentNullException: Value cannot be null. (Parameter 'text')`). These are the only inputs on which 3.31.0 throws. |

**Fonts with only old-style Indic script tags: none.** Every Indic test font
has the new-style tag, and most have both:

| Font | Script tags |
|---|---|
| Devanagari | `deva`, `dev2` |
| Bengali | `beng`, `bng2` |
| Kannada | `knda`, `knd2` |
| Telugu | `telu`, `tel2` |
| Tamil | `taml`, `tml2` |
| Malayalam | `mlym`, `mlm2` |
| Gurmukhi | `gur2` only |
| Gujarati | `gjr2` only |
| Odia | `ory2` only |

So the corpus has no such lines. If the shaper wants that case covered, the
font would have to be modified to remove its new-style tags, and it would
then be a fixture like those of d.6. Say so and I'll add it.

**Unpaired surrogates.** In 3.31.0 an unpaired surrogate gives glyph 0
(`.notdef`) with the font's `.notdef` advance, one glyph per unpaired unit.
The contract says to treat it as U+FFFD, and none of these fonts has a glyph
for U+FFFD, so both lead to `.notdef`.
