# Experiments

One file per experiment, `E-nnnn.md`:

- Hypothesis: what you think the expected outputs show, and why the spec does not settle it.
- Cases: how many gate cases it concerns, with a few ids.
- Command: the gate command you ran.
- Before / after: pass counts.
- Conclusion, and the rules it created or changed (R-MD-nnnn), and the rule-5 case (R5-nnnn).
